Push notification flow — cheatsheet

reference · print this out

Term What it is (plain English) In CUE's code
Push Provider The postal service. Holds everyone's mailboxes. Google (Chrome), Mozilla (Firefox), Apple (Safari). External — not in your code
Service Worker A background script that survives tab close. Receives push letters from the provider and shows system notifications. frontend/…/src/sw.js
PushSubscription The "mailbox address + lock key". One per device. Has: endpoint (address), p256dh (public key), auth (shared secret). frontend push.js → backend PushSubscription entity
VAPID Keys Your app's keypair. Public key goes to the browser to register; private key stays on the backend to sign/encrypt letters. Proves your app owns the mailbox. VAPID_PUBLIC_KEY (frontend .env.local) · VapidConfig.java (backend env vars)
Scheduler The background clock. Runs every 60s, asks "are any reminders due?", sends push to each. ReminderScheduler.java (@Scheduled 60s)
PushSender An interface (a contract). The scheduler only knows this — it doesn't know about HTTP, VAPID, or Google. The real work is in WebPushSender. PushSender.java (interface) → WebPushSender.java (implementation)
Payload The letter itself: {title, body, url}. Encrypted with the device's keys so only that device can read it. WebPushSender.buildPayload() → sw.js event.data.json()
@Scheduled Spring's timer annotation. Runs a method on a fixed schedule. Requires @EnableScheduling on the main app class. NexusBackendApplication.java (@EnableScheduling) · ReminderScheduler.java

The 7 hops (fast reference)

  1. push.js → ask permission → PushManager.subscribe() → get subscription (address + lock)
  2. push.js → POST /api/push-subscriptions → backend saves to Postgres
  3. ReminderScheduler → @Scheduled(60s) → DB query: due + unfired reminders
  4. ReminderScheduler → PushSender.send(userId, title, body, route) — interface call
  5. WebPushSender → find device subscription → encrypt with VAPID private key → POST to endpoint
  6. Push Provider → delivers to device → wakes up service worker push event
  7. sw.js → showNotification() → system notification appears
